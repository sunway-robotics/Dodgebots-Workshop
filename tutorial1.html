1.2 Steps of Assembly of Car Base

Step 1: Insert the fasteners and fix the motors to the chassis one by one, then tighten the screws and nuts.

Attention:

  • The motors should face each other with the copper tabs of their leading wires pointing outward.
  • The screw heads (the blunt ends) should also be pointing outward.

Step 2: Hold the chassis tightly and insert the wheels to the motors.

Step 3: Insert the standoffs, tighten them with screws from the bottom, then with screws from the upper side. Installation is then completed.

1.4 Buck Converter

5V Fixed USB Buck Converter

What is a Buck Converter?

A buck converter is a DC-to-DC power supply that reduces a higher input voltage to a lower output voltage.

*Direct Current (DC): electric current that flows in one direction only.

Why we need it:

  • Two 18650 batteries in series provide 7.4V nominal (up to 8.4V fully charged), but the ESP32 only operates at 3.3V–5V.
  • A buck converter steps down the voltage safely to 5V, preventing damage.
  • It provides stable voltage, avoiding resets, and efficiently supplies the required current.

5V Fixed USB Buck Converter

  • Input voltage: DC 7.5 - 28V
  • Fixed Output Voltage: 5.0V DC
  • Output Current: 2A Continues (3A peak)

1.5 L298N Motor-Driver

1.5.1 Output Terminals (OUT1, OUT2, OUT3, OUT4)

Motors A (Left Side) Motors B (Right Side)
  • Black wires → OUT1
  • Red wires → OUT2
  • Red wires → OUT3
  • Black wires → OUT4

*NOTE: Ensure that for both Motors A and B, each output terminal has the red wires paired together and the black wires paired together. DO NOT mix positive and negative wires in the same terminal.

1.5.2 Power Pins (VCC, GND, 5V)

VCC (+12V)
  • Main power input for motors
  • Often labeled +12V, but supports 5V–46V DC

*NOTE: However, TT motors receive slightly less voltage than supplied to VCC. To learn more: Power Pins - Last Minute Engineers

GND
  • Common ground for the module
  • Motor power supply and ESP32 must share this ground

*NOTE: Common ground connecting the ESP32 and battery is required for the signals to function correctly.
5V
  • Supplies power to the chip’s internal logic

*NOTE: This pin can usually be ignored, as the driver is able to draw power from VCC and automatically provides 5V to the logic circuits.

To learn more: On-board 5V Regulator and Jumper - Last Minute Engineers

1.5.3 Direction Control Pins (IN1, IN2, IN3, IN4)

The motor driver has two direction control pins for each motor. The IN1 and IN2 pins control the spinning direction of motors A, while the IN3 and IN4 pins control the spinning direction of motors B.

By setting different combinations of HIGH or LOW signals on these pins, you can make the motors spin forward, backward, or stop.

IN1, IN2 (Motors A) IN3, IN4 (Motors B)
  • IN1 HIGH + IN2 LOW → forward
  • IN1 LOW + IN2 HIGH → reverse
  • IN1 LOW + IN2 LOW → stop
  • IN3 HIGH + IN4 LOW → forward
  • IN3 LOW + IN4 HIGH → reverse
  • IN3 LOW + IN4 LOW → stop

2.0 ESP32 & Bluetooth

2.1 What is ESP32?

ESP32 is a powerful microcontroller used in robotics, IoT, and automation projects. It comes with:

  • Dual-core processor (up to 240 MHz)
  • WiFi + Bluetooth
  • Multiple GPIO pins
  • ADC (Analog inputs)
  • PWM pins for motors/servos
  • UART, I2C, SPI communication support

Power Pins

  • 3.3V → Power sensors & logic
  • 5V → Input from USB
  • GND → Common ground

GPIO Pins

Flexible pins used for digital input/output.

ADC Pins (Analog Input)

  • Pins 32, 33, 34, 35, 36, 39

    • PWM Pins (Servo/Motor Signal)

    Almost all GPIOs support PWM

    Best to use: GPIO 18, 19, 21, 22, 23, 25, 26, 27

UART Pins (Serial Communication)

  • TX0/RX0 (default)
  • Can remap to other GPIOs

Step 5: Controlling the Robot Car

#include <BluetoothSerial.h>
BluetoothSerial SerialBT;

#define IN1  33
#define IN2  25
#define IN3  26
#define IN4  27

void setup() {
  SerialBT.begin("ESP32Bot");  // Change according to your team name
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT);
  pinMode(IN4, OUTPUT);

  // Start fully stopped
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, LOW);
}

void loop() {
  if (SerialBT.available()) {
    char c = SerialBT.read();
    handleCommand(c);
  }
}

void handleCommand(char c) {
  if (c == 'F') {        // Forward
    digitalWrite(IN1, HIGH);
    digitalWrite(IN2, LOW);
    digitalWrite(IN3, HIGH);
    digitalWrite(IN4, LOW);
  }
  else if (c == 'B') {   // Backward
    digitalWrite(IN1, LOW);
    digitalWrite(IN2, HIGH);
    digitalWrite(IN3, LOW);
    digitalWrite(IN4, HIGH);
  }
  else if (c == 'L') {   // Left
    digitalWrite(IN1, HIGH);
    digitalWrite(IN2, LOW);
    digitalWrite(IN3, LOW);
    digitalWrite(IN4, LOW);
  }
  else if (c == 'R') {   // Right
    digitalWrite(IN1, LOW);
    digitalWrite(IN2, LOW);
    digitalWrite(IN3, HIGH);
    digitalWrite(IN4, LOW);
  }
  else if (c == 'S') {   // Stop
    digitalWrite(IN1, LOW);
    digitalWrite(IN2, LOW);
    digitalWrite(IN3, LOW);
    digitalWrite(IN4, LOW);
  }
}
